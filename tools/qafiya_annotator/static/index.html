مرجع القافية
الرَّوِيّ
Rawiy — main rhyme consonant
آخر حرف صامت جوهري في نهاية كل شطر عجز. يجب تكراره في جميع الأبيات.
مَنْزِلِ ← لالأَمِيرُ ← ر
الرِّدْف
Radf — long vowel before rawiy
حرف مدٍّ (ا،و،ي) يسبق الرَّوِيّ مباشرةً. إذا وُجد في بيت لزم في جميع الأبيات.
نَارُ ← ردف انُورُ ← ردف وسَيْرُ ← ردف ي
الوَصْل
Wasl — letter after rawiy
حرف يلحق الرَّوِيّ — يكشف حركته بقانون صوتي صارم:
و بعد الروي ← ضمة
ي بعد الروي ← كسرة
ا بعد الروي ← فتحة
ن بعد الروي ← تنوين
ه بعد الروي ← وصل بالهاء
يَقُولُونَ ← روي ل + وصل و
الحَرَكة
Harakah — vowel on rawiy
مفتوحة: فتحة (وصل ا أو ن)
مكسورة: كسرة (وصل ي)
مضمومة: ضمة (وصل و)
مقيدة: سكون — لا وصل
ـون ← مضمومةـين ← مكسورة ـان ← مفتوحةـلْ ← مقيدة
التَّأْسِيس
Ta'siis — alif two before rawiy
ألف قبل الرَّوِيّ بحرف واحد — إذا وُجد وجب في كل الأبيات.
عَاقِلْ ← ع+ا+ق+ل
النَّوع
Type — mutaharrikaat between last two saakins
متواتر: ١ متحرك — شَجَنْ، عَزِيزَانِ
متدارك: ٢ متحرك — الْعَنْبَرِ، قَمَرٌ
متراكب: ٣ متحركات — الْفَرَجِ، الْأَدَبِ
متكاوس: ٤ متحركات — فَجُبِرْ (نادر)
مترادف: ساكنان متلاصقان — دِينْ، عَيْنْ
عَزِيزَانِ ← متواتر ✓ الْفَرَجِ ← متراكب دِينْ ← مترادف
عيوب القافية
Defects
الإيطاء: تكرار كلمة الروي
الإقواء: خلط الكسر والضم
الإصراف: خلط الفتح مع غيره
السِّناد: تناقض الردف
الإجازة: تغيير حرف الروي
